# 대전세종목공기술학원 방문 예약 웹앱

회원은 카카오톡으로 받은 링크를 눌러 **로그인 없이** 방문 날짜와 시간, 할 작업을 예약해요.
원장님 두 분(고명균 `kommy9`, 이문회 `wood77`)은 같은 페이지의 **원장 메뉴**에서 각자 아이디·비밀번호로 들어가 주간 일정, 하루 준비표, 회원 기록을 봐요.
모든 데이터는 원장님 구글 드라이브의 **구글 시트**에 쌓여서 엑셀처럼 직접 열어볼 수도 있어요.

## 파일 구성

| 파일 | 하는 일 |
|---|---|
| `index.html` | 회원과 원장님이 보는 화면 |
| `config.js` | 서버 주소를 적는 곳 (설치할 때 한 번만 수정) |
| `core.js` | 예약 규칙 (정원, 겹침 확인, 취소 등). 화면의 체험 모드와 서버가 함께 씀 |
| `server/Code.gs` | 구글 시트에 붙여넣을 서버 코드 (`build.sh`로 자동 생성) |
| `server/sheets-adapter.js` | `Code.gs`를 만드는 재료 중 구글 시트 연결 부분 |

`config.js`가 비어 있으면 **체험 모드**로 돌아가요. 이 기기에만 저장되고, 원장 메뉴는 아이디 `kommy9` 또는 `wood77`, 비밀번호 `1234`로 들어가요.

---

## 설치 방법 (처음 한 번, 약 15분)

### 1단계: 구글 시트에 서버 만들기
1. 원장님 구글 계정으로 [구글 시트](https://sheets.google.com)에서 **빈 스프레드시트**를 만들고 이름을 `목공방 예약`으로 바꿔요.
2. 메뉴 **확장 프로그램 → Apps Script**를 열어요.
3. 편집기에 있는 `Code.gs` 내용을 모두 지우고 `server/Code.gs` 파일 내용을 **전부** 붙여넣은 뒤 저장(💾)해요.
4. 위쪽 함수 선택 칸에서 `setup`을 고르고 **실행**을 눌러요.
   - 처음에는 "권한 검토"가 떠요. 원장님 계정 선택 → **고급 → (안전하지 않음)으로 이동 → 허용**을 눌러요. 원장님이 직접 만든 코드라서 나오는 안내예요.
   - 시트에 `예약`, `회원`, `설정` 탭이 생기면 성공이에요.
5. 왼쪽 **⚙ 프로젝트 설정 → 스크립트 속성 → 스크립트 속성 추가**를 눌러 원장 두 분의 비밀번호를 각각 넣어요.

   | 속성 | 값 | 누구 |
   |---|---|---|
   | `PW_kommy9` | 고명균 원장님 비밀번호 | 아이디 **kommy9** |
   | `PW_wood77` | 이문회 원장님 비밀번호 | 아이디 **wood77** |

   - 비밀번호는 **8자 이상**, 영문과 숫자를 섞어 주세요. 회원에게 알려주지 마세요.
   - 비밀번호를 바꾸려면 이 값만 고치면 돼요. 다시 배포할 필요는 없어요.
   - `setup`을 한 번 더 실행하면 빠진 비밀번호가 있는지 실행 로그에 알려줘요.

### 2단계: 웹 앱으로 배포하기
1. Apps Script 오른쪽 위 **배포 → 새 배포**를 눌러요.
2. 톱니바퀴에서 유형 **웹 앱**을 골라요.
   - 실행 계정: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
3. **배포**를 누르면 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사해요.
4. `config.js`의 `API_URL: ""` 따옴표 안에 그 주소를 붙여넣어요.

### 3단계: GitHub Pages로 공개하기
1. GitHub(kommynine)에서 새 저장소 `woodshop-booking`을 **Public**으로 만들어요.
2. 이 폴더의 파일을 모두 올려요 (`index.html`, `config.js`, `core.js`, `server/` 등).
3. 저장소 **Settings → Pages**에서 Source를 **Deploy from a branch**, Branch는 **main / (root)**로 두고 저장해요.
4. 1~2분 뒤 아래 주소로 열려요.
   **https://kommynine.github.io/woodshop-booking/**
5. 이 주소를 카카오톡 단톡방 공지에 올려 두면 회원들이 바로 예약할 수 있어요.

## 운영하면서

- **정원·운영 시간·장비 목록**은 원장 메뉴 → 회원·설정에서 바꿔요. 시트의 `설정` 탭을 직접 고쳐도 돼요.
- **시트에서 직접 고칠 때**: 열 제목(첫 줄) 글자는 바꾸지 마세요. 열 순서는 바꿔도 돼요.
- **누가 처리했는지**: 예약 상태를 바꾸거나 메모를 남기면 시트의 `처리한 원장` 열과 예약 상세 화면에 이름이 남아요.
- **원장을 더 추가하려면**: Apps Script의 `ADMIN_USERS_` 목록에 `["아이디", "이름"]` 한 줄을 넣고, 스크립트 속성에 `PW_아이디`를 추가한 뒤 새 버전으로 배포해요.
- **회원 구분**은 이름 + 휴대폰 뒷자리 4자리예요. 같은 이름이라도 뒷자리가 다르면 다른 회원이에요.
- **서버 코드를 고친 뒤에는** 배포 → 배포 관리 → ✏️ 수정 → 버전 **새 버전** → 배포를 눌러요. 이렇게 하면 웹 앱 주소가 그대로 유지돼요. ("새 배포"를 누르면 주소가 바뀌어요.)
- **백업**: 구글 시트는 자동으로 버전 기록이 남아요 (파일 → 버전 기록).

## 개발 메모

- 예약 규칙은 `core.js` 한 곳에만 있어요. 고친 뒤 `./build.sh`를 실행하면 `server/Code.gs`가 다시 만들어져요.
- 화면은 `fetch(API_URL, {method:"POST", body: JSON})` 하나로 서버와 통신해요.
  - 회원용 요청: `config`, `slots`(이름 없이 시간만), `book`, `mine`, `cancel`
  - 원장용 요청(`adminId` + `pin` 필요): `adminCheck`, `adminData`, `setStatus`, `setNote`, `deleteBooking`, `saveMember`, `deleteMember`, `saveConfig`
- 회원 화면에는 다른 회원의 이름이 보이지 않아요. 남은 자리 계산용 시간만 내려가요.
